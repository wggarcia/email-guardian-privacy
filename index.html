Política de Privacidade — Email Guardian AI

Última atualização: 20 de agosto de 2026

O Email Guardian AI ("aplicativo", "nós") respeita a sua privacidade. Esta política explica, de forma transparente, quais dados o aplicativo acessa, como eles são usados e com quem são compartilhados.

1. Dados que o aplicativo acessa

O aplicativo acessa a sua conta de e-mail (Gmail e/ou contas IMAP) somente após a sua autorização explícita, para analisar mensagens em busca de ameaças (phishing, golpes e spam). Os dados acessados incluem:

  • remetente da mensagem;
  • assunto da mensagem;
  • um trecho do conteúdo do e-mail (até aproximadamente 1.000 caracteres).

O aplicativo não acessa anexos e não lê o corpo completo das mensagens.

2. Como os dados são processados

Para classificar cada e-mail como seguro, suspeito ou perigoso, o remetente, o assunto e o trecho descritos acima são enviados, por conexão criptografada (HTTPS), a um servidor de processamento próprio (Cloudflare Workers), que os encaminha a um provedor de inteligência artificial (Anthropic — modelo Claude) exclusivamente para gerar a análise de segurança e devolvê-la ao aplicativo.

  • Esse processamento é transitório: os dados são usados apenas para produzir a análise daquela mensagem e não são armazenados em nossos servidores.
  • Os dados não são usados para publicidade, não são vendidos e não são utilizados para treinar modelos de inteligência artificial.
  • Não mantemos banco de dados com o conteúdo dos seus e-mails. As credenciais de acesso ficam armazenadas de forma segura apenas no seu próprio dispositivo.

3. Uso Limitado (Google API Services User Data Policy)

O uso e a transferência, pelo Email Guardian AI, de informações recebidas das APIs do Google obedecem à Política de Dados de Usuários dos Serviços de API do Google (Google API Services User Data Policy), inclusive aos requisitos de Uso Limitado (Limited Use).

Email Guardian AI's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Compartilhamento com terceiros

Não compartilhamos seus dados com terceiros, exceto com os provedores estritamente necessários para executar a análise de segurança solicitada por você:

  • Cloudflare, Inc. — infraestrutura de processamento das requisições;
  • Anthropic — provedor do modelo de inteligência artificial que gera a análise.

Esses provedores tratam os dados apenas para devolver o resultado da análise, conforme as políticas de privacidade deles.

5. Exclusão e retenção de dados

  • Como os dados de e-mail não são armazenados em nossos servidores, não há histórico a ser excluído do nosso lado.
  • Você pode revogar o acesso do aplicativo à sua conta a qualquer momento, em myaccount.google.com/permissions (para o Gmail) ou removendo a conta dentro do próprio aplicativo.
  • Desinstalar o aplicativo apaga todos os dados e credenciais guardados localmente no seu dispositivo.
